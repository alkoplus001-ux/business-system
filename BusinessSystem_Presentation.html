GST — Puri Handling

Intra-state aur inter-state dono handle karta hai — auto calculate, PDF mein bhi, Tally mein bhi

🏠

Intra-State Sales

CGST + SGST — same state ke andar
e.g. 12% GST = CGST 6% + SGST 6%
Challan PDF mein clearly dono dikhte hain

✈️

Inter-State Sales

IGST — alag state ko bhejna
e.g. 12% GST = IGST 12%
PDF mein alag line item dikhta hai

📄

TallyPrime Open Karo

2

F12 → Advanced Configuration

Tally Gateway Server Enable Karo

Sahi Company Open Karo Tally Mein

System Mein Company Name Set Karo

Connection Test Karo

Common Issues
